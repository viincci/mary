# Mary Lwate Project
## Overview
This project is a Django application that showcases Mama Mary Lwate's work with the Good Hope Community Organisation. The organisation was founded by Mama Mary Lwate in 1997 to care for abused and abandoned children.
## Key Features
- User-friendly interface to display information about Mama Mary Lwate and the Good Hope Community Organisation
- Awards and recognition section to showcase Mama Mary Lwate's achievements
- Services section to highlight the organisation's services and activities
- Contact section for users to get in touch with the organisation
## Tech Stack
- Django as the web framework
- SQLite as the database
- HTML, CSS, and JavaScript for the frontend
## Installation
To install the project, follow these steps:
1. Clone the repository: `git clone https://github.com/username/mary.git`
2. Navigate to the project directory: `cd mary`
3. Install the required packages: `pip install -r requirements.txt`
4. Run the migrations: `python manage.py migrate`
5. Run the development server: `python manage.py runserver`
## Usage
To use the project, simply navigate to `http://localhost:8000` in your web browser.
## Environment Variables
The project uses the following environment variables:
- `SECRET_KEY`: the secret key for the Django project
- `DEBUG`: a boolean indicating whether the project is in debug mode
Note: These variables should be set in a `.env` file or in your operating system's environment variables.
